# UTEC Core Engineering

¡Bienvenido/a a mi repositorio de aprendizaje de Python!

Este repositorio contiene ejercicios y prácticas realizados durante el curso de **UTEC Core Engineering**, con el objetivo de desarrollar y fortalecer mis conocimientos de programación.

## 📚 Contenido del repositorio

En este repositorio encontrarás diferentes temas:

- **Python Fundamentals:** ejercicios sobre los fundamentos de Python.
- **Python Advanced:** ejercicios de conceptos avanzados, incluyendo manejo de archivos.
- **Python OOP:** prácticas de Programación Orientada a Objetos (POO), clases y objetos.
- **Structured Output:** ejercicios relacionados con la organización de datos.

## 🐍 Tecnologías utilizadas

- Python 3
- Git
- GitHub

## 🎯 Objetivo

Practicar, aprender y mejorar mis habilidades de programación mediante la resolución de ejercicios y la creación de pequeños proyectos.
