# UTEC Core Engineering

Repositorio de ejercicios y prácticas de fundamentos de programación en Python.

## Estructura

- `python_fundamentals/`: ejercicios de fundamentos de Python.
- `python_fundamentals/core_data_structures/`: ejercicios sobre estructuras de datos.

## Ejercicio: print_list_integer

El archivo `python_fundamentals/core_data_structures/print_list_integer.py` contiene una función que imprime los enteros de una lista, uno por línea.
